# Research and ATS test email

The monitor now researches a bounded default universe plus saved watchlist instead of falling back to AAPL alone. It sorts by a transparent three-condition trend screen; this is not a best-trade recommendation or a return forecast. Every company retains dated source data and a reassessment note. API rate limits and data gaps can leave incomplete coverage. Morning and next-day emails include a black-and-gold HTML alternative and plain-text fallback.

One-time resume test: upload an original resume, import a real posting, generate a tailored resume, review and approve it, then press SEND ONE ATS RESUME TEST EMAIL in Application Desk and confirm. This sends the latest approved draft as a text-based PDF to amazingchefadrian@gmail.com using SMTP configured on the user's PC. SMTP acceptance is not inbox confirmation. No employer application is submitted.

Local smoke tests: run existing unit tests, preview `python trading_monitor.py morning --force` without --send, verify all data labels, check HTML in an email client, and test resume delivery with owner approval. Do not enable scheduled tasks or merge without owner approval. No email has been sent by this GitHub change.
